# AAT Standard Events test page

This static page supports manual testing for these Standard Events POC behaviors:

- Full page loads
- Link clicks
- Form submit-control clicks

The page contains no Amazon source code, credentials, customer data, or internal test identifiers.

## Run locally

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Open `http://localhost:8080/`.

## GitHub Pages

Configure GitHub Pages to deploy from the `main` branch and the repository root.
